- (event) Import: Apple HIG Design principles (https://developer.apple.com/design/human-interface-guidelines/design-principles) supplied by user as design-principle inspiration. Adopted as principles, not as Apple visual mimicry (visual direction still open).
- (decision) Arrangly design principles (adapted from Apple HIG) — P1 Purpose/Lead, don't chase: every screen answers 'what needs me now?'; Dashboard state readable without messaging anyone (SM-5).
- (decision) P2 Agency/AI proposes, people decide: every AI suggestion is a visible, individually confirmable proposal (FR-6, FR-16); guided flows (questionnaire, RSVP) skippable; mistakes reversible — obsolete not deleted, decisions re-runnable (FR-11).
- (decision) P3 Responsibility/Show only what your role needs: RBAC is felt in the UI — people see their scope, never others' private data (allergies to owning Role only, §4.9); be explicit about what Arrangly does (never sends email itself, FR-14; PIN tradeoff stated plainly).
- (decision) P4 Familiarity/Borrow what people know: task lists, swimlanes, invites and RSVP use established web patterns; one status vocabulary with consistent colour/icon/wording everywhere (FR-8); clear feedback on every state change.
- (decision) P5 Flexibility/Meet each person where they are: Organizer planning on a larger screen, Role-holder and Guest often on a phone; guest side works at 375px; accessibility from the start (keyboard, screen reader, contrast, never colour-only status).
- (decision) P6 Simplicity/Every element earns its place: the Guest never sees planning machinery; Role-holder understands their task within ~1 minute (SM-3); plain words over jargon; clear hierarchy of now / next / later.
- (decision) P7 Craft/Care about the details: precise microcopy, considered empty/loading/error states, smooth but restrained motion; honest AI labelling (approximate info flagged).
- (decision) P8 Delight/Make it human: it's a celebration, not a project audit — warmth where it matters (published event, RSVP confirmed, task done, guest need resolved automatically) without noise on working screens.
- (decision) Mood: calm. Core feeling = Arrangly takes the weight off the organizer's shoulders.
- (decision) Look: clean, simple, Apple-platform-like; should feel instantly familiar, nothing to 'learn'. Light theme default; dark mode available as user preference.
- (decision) Form factor: multi-surface responsive web. Organizer (Leah) primarily desktop; Role-holders (Stine) and Guests (Chris) primarily phone.
